# Operations Intelligence 0.4.1 reviewer demo

Service KPIs and six-week workload scenarios, captured from the 0.4.1 build on November 14, 2026 using fictional data.

Extract the ZIP, open `index.html` in a browser, and use the links across the top. The offline pages show the recorded results and provide a sanitized JSON record. The application and its backend are private for this edition.

The earlier [0.3.1 public source](https://github.com/Jnapier2/operations-intelligence-platform/tree/de200badc17dbae19e020f1e699d1fb062128355) remains available.
